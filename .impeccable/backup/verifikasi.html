Verifikasi batch obat

Halaman ini hanya memanggil fungsi baca pada smart contract, jadi dapat dipakai tanpa menghubungkan wallet. Hasil yang tampil adalah data yang benar-benar tersimpan pada blok, bukan contoh.

Cari batch

Masukkan data yang tercetak pada kemasan atau tempel Batch ID langsung.

Tercetak pada kemasan, biasanya diawali kode wilayah. NIE wajib diisi.
Kode batch wajib diisi.
Nomor serial wajib diisi.
Kontrak membentuk ID dengan keccak256(NIE + kode batch + nomor serial).
Buka tautan QR
Nilai 32 byte berawalan 0x, hasil dari fungsi computeBatchId(). Format Batch ID harus 0x diikuti 64 karakter heksadesimal.

Tautan dan QR verifikasi

Bagikan tautan ini pada kemasan atau label. Pemindai akan membuka halaman verifikasi dengan Batch ID terisi otomatis.

Panduan penggunaan dan pengujian

Seluruh langkah di bawah sudah dijalankan pada kontrak yang sama dengan yang dipakai website ini. Tidak ada data contoh yang disamarkan sebagai data blockchain.

1. Menyiapkan jaringan dan wallet

Website dapat dibuka langsung sebagai berkas lokal maupun melalui server statis. Pembacaan data verifikasi bekerja pada keduanya. Transaksi dari halaman yang dibuka lewat file:// bergantung pada kebijakan peramban; bila MetaMask tidak muncul, jalankan server statis di folder web.

LangkahPerintah atau tindakan
1Jalankan node lokal: npx hardhat node pada folder proyek.
2Deploy kontrak ke jaringan tersebut: npm run deploy:local.
3Perintah itu menulis web/abi/DrugTraceability.js dan web/contract-config.js secara otomatis.
4Jalankan server statis: npm run web, lalu buka alamat yang ditampilkan.
5Di MetaMask, tambahkan jaringan Hardhat Local dengan RPC http://127.0.0.1:8545 dan chainId 31337.
6Impor akun uji memakai private key yang dicetak oleh npx hardhat node pada terminal.
Private key pada node lokal hanya untuk pengujian. Jangan pernah memakai akun utama atau menyimpan seed phrase di dalam berkas proyek.

Untuk jaringan uji publik, isi variabel pada berkas .env lalu jalankan npm run deploy:sepolia. Panduan lengkapnya ada di docs/DEPLOY.md.

2. Mencoba setiap role

Urutan ini mengikuti alur distribusi obat dari pabrik sampai apotek.

Regulator akun #0

  1. Buka Dashboard dan hubungkan akun #0.
  2. Buka tab Aktor rantai pasok, masukkan alamat akun #1, pilih Pabrik, kirim transaksi.
  3. Ulangi untuk akun #2 sebagai Distributor dan akun #3 sebagai Apotek.
  4. Buka tab Recall batch untuk menandai batch bermasalah.
  5. Tab Permintaan pendaftaran menampilkan pengajuan dari pengguna lain pada peramban yang sama.

Pabrik akun #1

  1. Hubungkan akun #1. Dashboard menampilkan menu Pabrik.
  2. Tab Registrasi batch: isi NIE, kode batch, tanggal, dan nomor serial, lalu kirim.
  3. Catat Batch ID yang muncul pada panel pratinjau.
  4. Tab Transfer custody: pilih batch, isi alamat akun #2, kirim transaksi.

Distributor akun #2

  1. Hubungkan akun #2. Batch yang baru diterima muncul di tab Batch yang saya pegang.
  2. Periksa detail batch untuk melihat riwayat perpindahan.
  3. Teruskan custody ke akun #3 melalui tab Transfer custody.

Apotek / pasien akun #3 atau tanpa wallet

  1. Hubungkan akun #3 untuk melihat batch yang diterima.
  2. Gunakan Verifikasi Obat tanpa wallet untuk memeriksa batch.
  3. Masukkan NIE, kode batch, dan nomor serial untuk melihat status dan seluruh riwayat.

4. Batasan yang jujur perlu disebut

  • Kontrak dijalankan pada jaringan uji, bukan mainnet maupun blockchain permissioned Hyperledger.
  • Pendaftaran aktor tetap hanya dapat dilakukan regulator. Tidak ada fitur pemilihan role mandiri.
  • Permintaan pendaftaran disimpan pada peramban (localStorage), bukan pada ledger. Ini catatan kerja, bukan fitur blockchain.
  • Daftar batch disusun dari event kontrak. Bila daftar berkas event node lokal dibersihkan atau kontrak di-deploy ulang, riwayat daftar mulai dari nol sementara data lama tetap ada di blok sebelumnya.
  • Belum ada integrasi langsung dengan sistem BPOM maupun pemindai 2D barcode resmi.
  • Fungsi verifyAuthenticity() membuktikan batch terdaftar pada ledger, bukan membuktikan keaslian fisik produk.
